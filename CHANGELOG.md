# Changelog

All notable changes are recorded here. The public 1.1.0 release aligns the Burp extension, VS Code extension, and Python CLI at the same version.

- Added the packaged **Public bug bounty lessons** profile with eight attributed checks.
- Included skill instructions and provenance in model previews, external review packs, manual plans, and saved review metadata.
- Prevented historical report IDs from being accepted as application evidence.
- Added the safe Juice Shop test export.
- Added GitHub metadata, contributor/security documentation, cross-platform CI, dependency update configuration, and a tag-driven GitHub release workflow.
- Added public repository, issue tracker, license, and Python 3.12 metadata to the unchanged Python CLI 1.1.0 distribution.
- Removed direct LLM/provider/API-key functionality from the Burp Java extension.
- Added VS Code traffic-to-source mapping, bounded evidence previews, five review profiles, manual test plans, structured review validation, and external-assistant packs.
- Added deterministic Java/Python-to-VS Code contract fixtures and package/host/webview validation.
