# Local demonstration

This folder contains a synthetic BurpNexus export and illustrative application source. No server needs to run.

1. Install the 1.1.0 VSIX and open `repo` in a trusted VS Code workspace.
2. Run **BurpNexus: Connect Export to Source Repository**.
3. Select `export` as the traffic directory, then `repo` as the source directory.
4. Expect three captured endpoints mapped to route candidates, plus `/admin/audit` without captured traffic.
5. Select `GET /api/users/12`, prepare an authorization review, and inspect the handler and router-mount citations.
6. Save the pack to inspect it without a model account, or choose a model through the panel.

The export is generated by the Java regression suite. Example implementations and missing controls are deliberately incomplete. No vulnerability is asserted by this demonstration.
